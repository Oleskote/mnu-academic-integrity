# mnu-academic-integrity

## Лаборатория формы государства

Интерактивный тренажёр по теории государства (1 курс, тема «Форма государства»). Откройте [`forma-gosudarstva/index.html`](forma-gosudarstva/index.html) в браузере — установка не нужна.

- **Лаборатория:** модельное государство с переключаемыми формой правления, территориальным устройством, автономией и режимом; схемы, таблица «По конституции / На практике», заблокированные переходы с объяснениями и маршрут из 7 этапов с кейсами.
- **Тренировка:** 10 кейсов «Определи форму государства», 12 утверждений «Мифы и ловушки», 8 заданий «Предскажи последствия» — с итоговыми разборами.

Учебная модель, таблица переменных и источники: [`forma-gosudarstva/METHODOLOGY.md`](forma-gosudarstva/METHODOLOGY.md).
