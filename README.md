# mnu-academic-integrity

## «Структура эссе» — интерактивный тренажёр

Тема: форма государства (теория государства, 1 курс). Откройте [`struktura-esse/index.html`](struktura-esse/index.html) в браузере — установка не нужна.

- **Лаборатория:** модельное государство с переключаемыми формой правления, территориальным устройством и режимом; схемы, таблица «конституция / практика», маршрут из 7 этапов с кейсами и сборка абзаца эссе из модели.
- **Тренировка:** вводные слова, первое предложение абзаца (вопрос / факт / провокация), аргументы к тезису.

Учебная модель, таблица переменных и источники: [`struktura-esse/METHODOLOGY.md`](struktura-esse/METHODOLOGY.md).
